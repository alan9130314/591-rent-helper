# 591 租屋筆記

不需建置、無第三方套件的 Chrome Manifest V3 擴充功能。

## 通用版安裝（Windows / macOS）

Windows 與 macOS 共用同一份 `591-rent-helper` 原始碼資料夾，使用相同程式碼、功能及 JSON 備份格式。適用於桌面 Chrome，也可在 Microsoft Edge 載入；這份套件不是 Safari 擴充功能。使用時不需要安裝 Node.js 或 Python。

1. 將本專案資料夾保存在固定位置。資料夾內應包含 `manifest.json`、`popup.html`、`shared.js` 等檔案，可直接載入，不需要建置或壓縮。
2. Chrome 開啟 `chrome://extensions`；Edge 開啟 `edge://extensions`。
3. 開啟「開發人員模式」，點選「載入未封裝項目」（部分版本顯示「載入解壓縮」）。
4. 選取含有 `manifest.json` 的專案資料夾。
5. 釘選「591 租屋筆記」，重新整理已開啟的 591 租屋分頁即可使用。

### 更新現有安裝

安裝後請保留該資料夾。不論先前使用 Windows 版或 macOS 的原始版本，都將新版檔案複製並覆蓋到原安裝資料夾，再到擴充功能頁按「重新載入」。不要先解除安裝，以免刪除已儲存紀錄。有匯出功能的舊版可先匯出備份。

### 跨電腦移轉

Windows 與 macOS 的備份檔可互相匯入。先在原電腦「匯出紀錄」，再到另一台電腦「匯入紀錄」。資料不會自動跨電腦或跨瀏覽器同步。沒有匯出按鈕的舊版，先依上方方式更新即可。

## 使用方式

- 每張物件卡片左上角提供整合狀態顯示與操作的精簡選單（不再另外顯示狀態標籤），以文字與顏色顯示目前狀態，滑鼠停留時可查看已有備註，可直接選擇「已看過」、「不考慮」或「有興趣」。選單以浮動方式呈現，不占用原本卡片的排版空間。修改狀態會保留已有的標題與備註；選「取消標記」會移除該物件紀錄（包含備註）。同一物件的其他卡片與擴充功能會同步更新，動態載入的卡片也支援。


- 點擴充功能圖示，輸入物件 ID 或貼上租屋物件網址，選擇「已看過」、「不考慮」或「有興趣」，可加上名稱或備註。
- 在 591 物件頁點開擴充功能，會出現「加入目前物件 #ID」。選擇狀態後點擊即可加入，不必填網址。已有紀錄時顯示「更新目前物件」；未填備註會保留原備註。非物件頁不顯示此按鈕。
- 同一物件的 ID 與不同追蹤網址會合併為一筆；再次新增會更新狀態與備註。
- 在 591 列表左下角，或擴充功能內的「591 列表顯示」，選擇全部、只看未標記、隱藏不考慮或個別狀態。
- 「我的紀錄」可搜尋、編輯、變更狀態及移除。移除後可按「復原」（關閉視窗後即無法復原）。
- 頁面的工具列可收合；狀態及篩選設定會在已開啟的租屋分頁同步。

支援的輸入格式：
- 21964749（正整數物件 ID，前後空白會自動移除）
- https://rent.591.com.tw/21964749
- https://rent.591.com.tw/rent-detail-21964749.html
- https://www.591.com.tw/rent-detail-21964749.html

網址中的追蹤參數與錨點會移除。不接受列表、出售物件或非 591 網址。分享短網址需先開啟，複製轉址後的租屋物件網址。

## 範圍與隱私

- 僅在 https://rent.591.com.tw/ 頁面執行。支援桌面一般列表與精選推薦。
- 手動設定狀態，不會因為點開物件就自動標記。
- 只篩選網頁已載入的物件，包含動態載入；不會改變網站的搜尋總數或自動補滿每頁物件。
- 同一物件在列表與推薦重複出現時都會套用；工具列筆數計算的是卡片出現次數。
- 資料使用 chrome.storage.local，只在這個 Chrome 使用者設定檔保存，不會上傳紀錄、不跨裝置同步。解除安裝擴充功能會刪除資料。
- 要求 storage 與 activeTab 權限；activeTab 僅在點開擴充功能時讀取目前分頁網址，沒有遠端程式、追蹤碼、第三方服務。
- 非 591 官方工具。591 改版可能需要調整 content.js 的物件選擇器。
- 無法辨識的容器不會被隱藏，避免誤刪頁面內容。地圖模式與行動版尚未驗證。

## 物件標題

紀錄主標題顯示物件名稱，備註另列。從目前頁面加入時使用分頁標題；手動加入或舊紀錄缺少標題時，會向該 591 物件頁讀取標題（不附帶登入 Cookie，單次最多等候 5 秒）。因此需要 rent.591.com.tw 的網站存取權限。失敗時暫顯示物件 ID，下次開啟擴充功能會重試。標題、編號與備註均可搜尋。

## 匯出與匯入紀錄

在擴充功能下方「備份與移轉」點「匯出紀錄」，下載 JSON 備份檔。匯出包含全部紀錄，不受目前搜尋或篩選影響，保留物件 ID、網址、標題、狀態、備註與更新時間，不包含列表篩選設定。

在另一台電腦或另一個瀏覽器安裝本版本，點「匯入紀錄」並選取備份檔（上限 10 MB）。預設保留本機同 ID 紀錄；如要使用備份內容，先選擇「以匯入紀錄覆蓋」。不在備份中的本機紀錄仍保留。匯入完成會顯示新增、覆蓋及保留筆數，591 分頁的標記會同步更新。

格式錯誤、不支援的備份版本、無效紀錄或重複 ID 會整份拒絕，不會部分匯入。空備份不會刪除任何紀錄。備份檔含完整備註，請自行妥善保存。沒有匯出功能的舊版須先更新本版本，才有匯出按鈕。

## 標題關鍵字隱藏

預設啟用「限女」、「社宅」、「社會住宅」。到擴充功能的「標題關鍵字隱藏」編輯清單（每行一個或逗號分隔），按「儲存關鍵字設定」套用。清空清單後儲存即可取消所有關鍵字。列表左下角的勾選框可暫停此功能。

只比對列表卡片的標題，不比對備註或一般描述；任一關鍵字命中即隱藏，採文字包含比對，不區分英文大小寫。此規則與物件狀態篩選同時套用，因此選「全部物件」時關鍵字仍有效，取消勾選即可顯示被關鍵字隱藏的物件。隱藏不會刪除紀錄或改變物件狀態。一般列表、推薦與動態載入均會套用，工具列顯示關鍵字命中筆數。

關鍵字設定保存在本機瀏覽器，不包含在紀錄 JSON 備份中。
